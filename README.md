# PSPO I Study Plan

A 4-week, day-by-day study planner for the Professional Scrum Product Owner I (PSPO I) exam.

- 28 days organized as four one-week Sprints, each with a Sprint Goal
- Daily tasks with checkboxes and links to free study resources
- "Today" card based on your chosen start date, plus a target exam day
- Practice score log with a chart and a readiness check (last 3 scores at 95%+)
- Cheat sheet tab: accountabilities, events and timeboxes, artifacts and commitments, EBM Key Value Areas, common traps
- Timed mock exam: 80 questions in 60 minutes from a bank of 91 original questions, with topic breakdown and answer review; scores log automatically
- Quick-check quiz with instant explanations
- Notes tab: multiple notes, autosave, search, copy all; add a note from any day card
- Study buddy: chat that knows the plan, cheat sheet, question bank, your scores and notes
  - Without a key it searches the app's study material (offline)
  - With a Claude API key (from console.anthropic.com) it becomes a full AI tutor; the key is stored only in your browser
- Progress is saved in your browser (no account, no server)

> Never put an API key in the files you upload to GitHub. Enter it only in the app's AI settings.

## Publish it on GitHub Pages

1. Sign in to GitHub and create a new public repository, for example `pspo-study-plan`.
2. Click **Add file → Upload files**, upload `index.html` and this `README.md`, then click **Commit changes**.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to *Deploy from a branch*, choose **main** and **/ (root)**, then click **Save**.
5. After a minute or two, the app is live at `https://<your-username>.github.io/pspo-study-plan/`.

## Notes

- Progress is stored in the browser you use. Opening the app on another device starts fresh.
- Content follows the 2020 Scrum Guide. Always treat the official guide at scrumguides.org as the final word.
